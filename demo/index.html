How to use Cypher

📤 Transmitting Files

  1. Select a file in the File Loader Slot.
  2. (Optional) Enter a Key Phrase for private/encrypted broadcast.
  3. Adjust Velocity (FPS) if needed.
  4. Click ▶ Start Loop to begin flashing QR codes.
  5. Use Popout to display in a separate window or Save video to record it.

📥 Receiving Files

  1. Enter the matching Key Phrase (if encrypted).
  2. Click Start Camera and point it at the transmitter's screen.
  3. Or upload a pre-recorded loop video using LOAD RECORDING....
  4. Keep the camera steady! The file downloads automatically when complete.
